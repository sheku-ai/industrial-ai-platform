# SHEKU Troubleshooting

Operational troubleshooting guidance for supported SHEKU runtimes and deployment configurations in the 1.6.x release line.

Troubleshooting must preserve authoritative product semantics: diagnose from persisted evidence and supported health/readiness contracts before relying on transient process state, caches or convenience flags.

Runtime defects must be corrected in the responsible runtime. Product Acceptance or readiness contracts must not be weakened to conceal failures.

Operational runbooks are maintained under `../operations/`.
