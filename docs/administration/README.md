# SHEKU Administration

Administration documentation for the SHEKU 1.6.x release line.

This section covers organization configuration, security, governed access, product configuration and administrative operations exposed through supported SHEKU contracts.

Routine administration must be configuration-driven and must not require source-code changes. Administrative UI state is not authoritative when persistent backend evidence exists.

Customer-specific roles, hierarchies, taxonomies and workflows must remain configurable rather than becoming fixed SHEKU product entities.
