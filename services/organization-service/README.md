# Organization Service

Foundation service for Sprint 1.

## Purpose

Manage the organizational model used by documents, permissions, search scopes, and AI context.

## Core objects

- companies
- areas
- departments
- countries
- sites
- systems
- assets
- roles
- users
- permissions
- relationships

## Design principle

Use hierarchy plus relationships. A plant can belong to one country, be operated by one area, and have technical ownership from another area.
